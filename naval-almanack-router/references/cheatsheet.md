# 决策规则速查 — 纳瓦尔宝典：财富与幸福指南

| 能力 | 一句话规则 |
|---|---|
| 时薪决策器 | 用高到离谱的个人时薪做过滤器——不做的损失、外包成本低于它则忽略/外包，否则亲自做。 |
| 财富结构诊断 | 诊断收入是否靠出租时间——没有股权/睡后收入就难财务自由，规划向所有权迁移。 |
| 专长发现器 | 回溯童年不费力之事+问亲近者，找到像玩耍般、无法被培训替代的专长。 |
| 杠杆阶梯 | 从出租时间转向无需许可的代码/媒体杠杆，以专长+责任为底座放大产出。 |
| 欲望审查器 | 每个"我想要"都是一份"得不到就不快乐"的自签契约——先把活跃欲望收敛到 ≤1 个。 |
| 接受三选一 | 面对任何处境只有三条路：改变、接受、逃避；卡在中间才是大多数痛苦，逼自己二选一。 |
| 幸福习惯替换 | 不要靠意志力改习惯，用"环境默认设置+替代品+新自我形象"替换坏习惯。 |
| 判断力工具箱 | 重大决策用"难以抉择即否定/迎难而上/反推法"；复杂问题先选对心智模型再推理。 |
| 四种运气 | 把运气拆四类，重点用第四种——把专长做到极致、建诚信声誉，让机会主动找上门 |
| 责任与声誉复利 | 以个人名义承担风险，社会按责任+股权+杠杆回报，声誉会复利放大 |
| 交友与长期主义 | 用五只黑猩猩理论筛选相处对象，按复利经营少数正直伙伴，不共事一生者一天不共事 |
| 诚实与极度坦诚 | 极度坦诚换内心自由，遵循"具体表扬、泛泛批评"，先不骗自己 |
| 退出地位游戏 | 识别零和竞争并选择不参与，把精力转向正和创造 |
| 嫉妒与愤怒消解 | 嫉妒用"100%交换人生"检查消解，愤怒视为自我惩罚契约而放下 |
| 生命公式自检 | 用「幸福=健康+财富+良好关系」等式链逐年自检，定位最薄弱变量优先补强 |
| 退休与内在自由重构 | 把退休重定义为「不再为明天牺牲今天」，把自由重定义为「不想做就不做」的内在无拘无束 |
| 阅读基础构建 | 以数学/科学/哲学经典与基础学科打阅读地基，读原著而非解读本，把真理置于社群认同之上 |
| 冥想与无选择觉知 | 用「无选择觉知」散步或每天静坐训练对念头的觉察，让心猿安静、达到收件箱为零的平静 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
