# 纳瓦尔宝典：财富与幸福指南 — 来源路由入口（compact pack）

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 心理疾病的诊断与治疗（抑郁、焦虑等需专业帮助，不可用本书方法替代）
- 需要集体行动与制度改变的公共议题（作者明确劝退政治参与，这是其立场盲点）
- 具体投资组合、税务、法律建议
- 把作者的饮食/冷水澡/生酮等个人实验当作普适处方

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 财富是睡觉时仍在赚钱的资产，出租时间不可能致富；路径是专长 + 杠杆 + 责任 + 股权 + 判断力 + 耐心
2. 专长不可被批量培训，只能从真正的兴趣里长出来；对你像玩耍、对他人像苦工
3. 优先使用无需许可的杠杆（代码、媒体），它们复制边际成本为零
4. 判断力被严重低估：杠杆时代方向比速度重要，一个正确决策胜过长时间努力
5. 欲望是你跟自己签的「得不到我就不快乐」的契约，削减欲望即削减痛苦
6. 面对不可改变的处境只有三条路：改变它、接受它、逃避它；逃避最常被误当作接受
7. 幸福是一种可训练的技能，靠环境设计与习惯替换，而非靠意志力
