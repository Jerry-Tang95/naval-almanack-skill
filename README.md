# naval-almanack-skill

> 《纳瓦尔宝典：财富与幸福指南》蒸馏出的 AI Agent Skill。把一本书压成一个可触发的路由入口 + 18 张能力卡，让 Agent 在真实对话里按意图加载，而不是让用户背知识点。

## 这是什么

这不是读书笔记，是一个**可安装的 Skill 包**：

- `SKILL.md` —— 路由入口。含「触发 / 不触发」边界、核心原则速览、意图→能力卡的路由表、加载规则、判停条件。
- `references/capabilities/` —— 18 张能力卡，每张对应一类真实诉求（要不要外包、退出地位游戏、嫉妒止损、欲望审查等）。
- `references/overview.md` `glossary.md` `cheatsheet.md` —— 概览、术语、决策速查。
- `references/capability-index.md` —— 完整意图 × 关键词索引，路由表没覆盖时查这里。
- `test-prompts.json` —— 触发测试用例（含 should_trigger / should_not_trigger / edge_case）。

## 设计要点（这类包能不能用，看这三点）

1. **先路由后加载。** 每次只加载 1 张卡（跨域最多 2 张），避免把整本书塞进上下文。
2. **负例是必需品。** `test-prompts.json` 里的 `should_not_trigger` 保证它不会在心理咨询、投资建议、诊断治疗这些场景乱入。
3. **有明确的判停条件。** 遇到病理性心理状态、结构性不公时停止方法论输出，转专业帮助或外部行动 —— 这是蒸馏边界，不是免责声明。

## 安装

### WorkBuddy / CodeBuddy / Claude Agent Skills

复制整个目录到用户级 skills 目录：

```bash
# Windows
cp -r naval-almanack-router ~/.workbuddy/skills/

# macOS / Linux
cp -r naval-almanack-router ~/.claude/skills/
```

放在项目级就是 `.workbuddy/skills/`（当前工作区内，团队共享）。

### 直接当 prompt 用

不需要 Skill 框架也能用：把 `SKILL.md` 的内容作为 system prompt，需要时把对应能力卡内容一起喂进去。

## 来源与限制

- 蒸馏自 Eric Jorgenson 编《The Almanack of Naval Ravikant》，作者观点不代表本仓库立场。
- **不适用场景**：心理疾病诊断治疗、需集体行动的公共议题、具体投资/税务/法律建议。作者的饮食与冷水澡等个人实验不应当普适处方。
- 内容属于二手转述，重要决策请以原书为准。
