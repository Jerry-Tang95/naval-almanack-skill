# naval-almanack-skill

> 把《纳瓦尔宝典：财富与幸福指南》蒸馏成一个**可触发的 Agent Skill**：18 张能力卡的来源路由入口。
> 不是读书笔记，不是金句合集 —— 它是一个会在真实对话里被激活、加载对应方法论、并在不该出面时闭嘴的路由系统。

```
你：「同事天天攀比职级薪资，我很累，怎么退出这种地位游戏？」
     ↓ 路由匹配
  status-game-exit 能力卡
     ↓ 联动
  envy-anger-dissolve + desire-audit
     ↓
  输出：退出零和比较、建立内在评价标准的具体路径
```

## 30 秒上手

### 安装

```bash
# WorkBuddy / CodeBuddy（Windows）
cp -r naval-almanack-router ~/.workbuddy/skills/

# Claude Code（macOS / Linux）
cp -r naval-almanack-router ~/.claude/skills/
```

项目级安装放在当前工作区的 `.workbuddy/skills/` 下，团队共享。

### 不用 Skill 框架也能用

把 `SKILL.md` 的内容作为 system prompt，需要时连同 `references/capabilities/` 下对应能力卡一起喂进去。

### 验证装好了没

随便挑一句下面的提问丢给 Agent，看它是不是按预期走了：

> 「我总觉得好机会都轮不到我，纳瓦尔说的四种运气到底是什么意思？」

如果它开始解释"盲运 / 坚持的运 / 察觉的运 / 独特个性吸引的运"，就是跑起来了。

| # | 提问 | 应该走哪儿 | 为什么不是本入口 |
|---|---|---|---|
| 11 | 我家水管漏了该自己修还是请师傅，哪个划算？ | `hourly-rate-triage` | 单件任务的三选一（忽略／外包／自己做），独立 Skill 更直接 |
| 12 | 我为什么这么努力还是穷，是不是该去拿点公司股权？ | `wealth-structure-audit` | 收入结构／是否"出租时间"的诊断，属于结构性分析 |
| 13 | 我连自己擅长什么都不清楚，更不知道该放大什么。 | `specific-knowledge-finder`（次选 `leverage-ladder`） | 专长发现与杠杆选择，是两个更大的话题 |
| 14 | 买完东西还是空虚，为什么我总是不满足？ | `desire-audit` | 欲望审查，日常高频，独立成 Skill 更合理 |
| 15 | 这段关系很痛苦该忍还是该走，卡在这里好难受。 | `acceptance-trilemma` | 改变／接受／逃避的三选一，边界清晰、触发率高 |

### 🔸 边界用例（1 条）

| # | 提问 | 期望行为 |
|---|---|---|
| 16 | 《纳瓦尔宝典》这本书的作者是谁、主要讲了什么？ | **不加载任何能力卡**。这是信息查询，由核心原则＋`overview.md` 直接回答，并说明本书范围。**同时不得给出投资／税务／法律的具体建议。** |

> 通过标准：`minimum_pass_rate = 0.8`。也就是说 16 条里允许错 3 条，但 `edge_case` 和负面用例错了就不是"小偏差"，是路由设计坏了。

## 为什么这么切：四个设计决策

**1. 先路由，后加载。**
每次只加载 **1 张**卡（跨域最多 2 张）。把整本书塞进上下文既浪费 token，也会稀释重点 —— Agent 会开始"综合全书来讲"，输出就变成了正确的废话。

**2. 负例是必需品，不是可选项。**
5 条 `should_not_trigger` 保证它不会在心理咨询、投资决策、法律税务这些场景里乱入。**一个只会"是"的 Skill 是危险的。** 这也是为什么这个包能带着边界上线，而不只是一个"纳瓦尔人格"。

**3. 有硬性的判停条件。**
遇到以下情况，方法论输出必须停止：

- 用户描述持续失眠、自伤念头、无法正常工作等病理性状态 → 转专业帮助
- 用户处境涉及真实的结构性不公或权力不对等 → 停止"向内归因"，转讨论外部可行行动
- 用户只是查信息（纳瓦尔是谁、书里说什么）→ 直接回答，不启动决策流程

第三条尤其重要：**别把查资料的人拖进一场人生咨询。**

**4. 晋级机制：从 router 到独立 Skill。**
先用一个总入口承接全部意图，跑一段时间看哪些卡真的被高频用到、边界是否清晰，再把这些卡升级成独立 Skill。避免了"一开始就为每句话建一个 Skill"的过度拆分。

## 关键术语

书里这些词的含义和日常用法不一样，理解偏差会导致整个方法论跑偏：

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 专长 | 无法被批量培训、只能靠真兴趣习得的知识 | 不是"技能"，核心判据是**不可培训**＋**源于好奇**；对你像玩耍、对别人像苦工 |
| 杠杆 | 劳动力、资本、"复制边际成本为零的产品"（代码／媒体） | 不只是财务杠杆；"**无需他人许可**"才是关键维度 |
| 承担责任 | 以个人名义承担商业风险 | 不是负面的"被追责"，而是**获取回报的前提** |
| 判断力 | 知道行为长期后果并据此决策的能力 | 与"努力"相对 —— 杠杆时代**方向 > 速度** |
| 欲望即契约 | 欲望是你跟自己签的"得不到我就不快乐"的合约 | 欲望不是动力，是**自选的痛苦** |
| 财富 | 睡觉时仍在赚钱的资产 | 不是工资、金钱或地位 |
| 退休 | 不再为想象中的明天牺牲今天 | 与年龄、存款都无关 |
| 四种运气 | 盲运、坚持、察觉、独特个性吸引 | 运气**部分可制造** |

完整 16 条见 `references/glossary.md`。

## 不适用场景

装上之前先看清楚这段 —— **这决定了会不会用错地方**：

- ❌ **心理疾病的诊断与治疗**（抑郁、焦虑等需专业帮助，本书方法不能替代）
- ❌ **需要集体行动与制度改变的公共议题**（作者明确劝退政治参与，这是他的立场盲点）
- ❌ **具体投资组合、税务、法律建议**
- ❌ **把作者的饮食／冷水澡／生酮等个人实验当普适处方**

## 这本书本身的局限

蒸馏过程里对原书做了一次批判性审查，结论一并保留 —— **用这个方法论时应该知道它的边界在哪**：

| 类型 | 具体问题 |
|---|---|
| 幸存者偏差 | 纳瓦尔是顶级 1% 投资人，案例几乎全是极端成功者（巴菲特、贝佐斯、扎克伯格）。对资本、时间缓冲都不足的普通受雇者，路径可复制性存疑 |
| 极致个人主义 | 把幸福、成败几乎全部归因于个人选择，弱化社会结构、制度与运气的作用 |
| 技术精英偏见 | 把科学／数学置于真理顶端，轻视人文、艺术、社群与政治参与 |
| AI 时代的挑战 | 素材集中在 2005–2019，"学会写代码／写文章"的稀缺性在生成式 AI 普及后被重写。结论方向没变，但**论据的说服力下降了** |
| "幸福是选择"的风险 | 把贫困、抑郁导致的不幸归因于"没选对欲望"，容易滑向受害者责难 |

纳瓦尔那句"把我一穷二白丢到任何英语国家，5–10 年我还能致富" —— 预设了他已掌握的赚钱技能、语言能力和当地制度环境。**对绝大多数人不成立。**

完整的批评见 `references/overview.md` 第 3 节。
